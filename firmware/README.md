# firmware/ (owner: A) - stub

PlatformIO (Arduino framework) project for the ESP32-S3 node, board `esp32-s3-devkitc-1` (N16R8).
Not built in the foundation; the hardware has not arrived. The node must speak contract v1 exactly
as `contract/CONTRACT.md` describes it. The simulator in `sim/` is the reference implementation of
a node's behavior (buffered late uploads, `ph_settling` flags after TDS reads).
